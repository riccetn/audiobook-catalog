Add books from an export

Pick an Audible Library Extractor CSV or a Goodreads library export. You see what would change before anything does.

Hardcover

Import adds the books on your Hardcover Read shelf, Export puts your books on it with their dates read, and Sync does both. Nothing is changed or removed on either side, and you see what would happen first.

Check the catalogue

Check lists errors and anything that needs a look, and anything kept in an older format, which it can save in the current one. Box sets keeps each box set both as its own book and as its titles, as imports do now; it shows what it would add before changing anything.

Export to Goodreads

Downloads a CSV of every book for Goodreads' import page: on the read shelf, with the latest date read, genres as shelves, and the Goodreads id and ISBN of an edition so Goodreads picks that edition.

Backups

The catalogue lives in this browser only, so export a backup now and then: it has the books, the series and author info and the list of books imports skip. Restore replaces the catalogue with a backup, or with the data files of a catalogue from before it lived in the browser (pick books.json, series-info.json, authors.json, excluded.txt and not-duplicates.txt together). Merge combines a backup from another device (your phone, say) with this catalogue when both have changed.
